Este proyecto es una aplicación web de una sola página (SPA) diseñada para presentar mi trayectoria profesional, habilidades y formación académica de una manera dinámica, moderna y amigable para el usuario, alejándose del formato estático tradicional.

## ✨ Características del Proyecto

* **100% Responsivo:** Diseño fluido que se adapta a dispositivos móviles, tablets y pantallas de escritorio.
* **Modo Oscuro / Claro:** Soporte nativo para cambio de tema (Dark Mode) con persistencia de preferencias del usuario usando `localStorage`.
* **Gráficos Dinámicos:** Visualización interactiva de habilidades técnicas utilizando Chart.js, con filtros por categoría (Redes, Sistemas, Desarrollo).
* **Navegación Intuitiva:** Interfaz de usuario tipo "Master-Detail" para explorar la experiencia laboral sin recargar la página.
* **Print-Ready (PDF):** Reglas de CSS exclusivas (`@media print`) que transforman la aplicación web interactiva en un documento lineal, limpio y estructurado, ideal para descargar como PDF o imprimir en papel.

## 🛠️ Tecnologías Utilizadas

* **Estructura:** HTML5 semántico.
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (vía CDN) para un maquetado ágil y moderno.
* **Interactividad:** JavaScript Vanilla (ES6+) para la lógica de navegación, filtros y modo oscuro.
* **Visualización de Datos:** [Chart.js](https://www.chartjs.org/) (Canvas) para el análisis de habilidades.
